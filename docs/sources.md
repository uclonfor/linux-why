# Interface references

- [pacman manual](https://man.archlinux.org/man/pacman.8.en): local query and ownership options; explicit/dependency reason flags.
- [systemd D-Bus interface](https://www.freedesktop.org/software/systemd/man/latest/org.freedesktop.systemd1.html): unit properties and relation semantics.
- [systemctl](https://www.freedesktop.org/software/systemd/man/latest/systemctl.html): `show` is intended for computer-parsable property output.
- [Linux procfs](https://docs.kernel.org/filesystems/proc.html): process identity, cgroups, descriptor links and visibility constraints.
- [Linux TCP proc tables](https://docs.kernel.org/networking/proc_net_tcp.html): address/state/inode layout; this older interface remains available, though inet_diag is preferred for new kernel tooling.

No documentation is fetched by the application. These are maintainer references.
