# Changelog

## 0.1.1 — Unreleased

- Added the official `why` console script, sharing the `linux-why` CLI entry point.

- Compact interactive ambiguity chooser with arrow/number selection and clean cancellation.
- Preserved non-interactive ambiguity JSON and explicit browser targets.

- Removed the Exit menu item; Installed packages is selected initially and Ctrl+Q quits.

- Interactive Textual mode on invocation without a target, with keyboard-first browsers.
- Instant Unicode search, background session inventories and the existing graph explanations.
- Runtime FIGlet banner with compact fallback; TTY checks and clean terminal restoration.

- Local explanations for packages, files, processes, units, ports, interfaces and modules.
- Arch pacman provenance and basic Debian dpkg ownership/version support.
- Shared graph with sourced claims, confidence, JSON schema and bounded traversal.
- Explicit disambiguation, partial-result exit codes and safe text rendering.
- Offline fixture tests, Linux integration tests, lint/type/build CI.
